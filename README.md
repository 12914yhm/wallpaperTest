# DWD

当前唯一维护的版本位于 [DWD.Native.Effects](DWD.Native.Effects/README.md)。源码、资源、测试和开发笔记均在该目录；可运行程序在本机 `DWD.Native.Effects/publish/DWDNative.exe`。

本仓库用 Git 管理源码和必要资源。`build`、`publish`、用户配置、使用时长记录、缓存及日志仅保留在本机，不纳入版本控制。修改后在项目目录按 README 的命令构建、测试并更新 `publish`，不再复制历史版本文件夹。

2026-10-05 清理旧版本时，旧版中与最新版不相同的少量使用时长文件保存在本机 `DWD.Native.Effects/publish/UsageData/Legacy`，不会自动混入当前统计；需要核对历史时可手动查看。
