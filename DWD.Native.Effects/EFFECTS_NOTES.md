# 体验与效果副本 · 2026-10-04

基于同级 `DWD.Native.Optimized` 完整复制源码、资源、测试、发布文件、配置和开发备忘。
构建中间文件不沿用旧目录中的绝对路径，已在本副本重新生成。原版与优化版未替换，不生成 ZIP。

## 运行与入口

运行 `publish/DWDNative.exe`。三版共用单实例机制，先从托盘退出当前版本再启动另一版。
只分发同一个应用 EXE；后台的播放器、效果预览和转码按需使用这个 EXE 的不同运行模式。
默认缓存位于本副本 `publish/Cache`，不写注册表；改成自定义缓存目录时保存所选目录。

主界面：收藏按钮；图库的“全部/收藏/最近”筛选；预览进度条；“画面效果”；“更多”。
“更多”中包含打开视频/图片、重新定位、暂停窗口预览、播放列表、屏幕与外观、恢复静态壁纸。
原设置按钮、使用时长、托盘行为仍保留。

## 新功能

### 设置交互修订（2026-10-04）

- 画质、全屏暂停规则、应用/取景屏幕、主题、缓存上限改为下拉选择，展开即可看到所有选项。
- 画质、全屏规则、主题下方随当前选项显示说明；播放设置仍需点击“应用到桌面”提交。
- “自定义背景颜色”直接打开颜色选择窗口，取消保留原主题；自定义状态显示颜色值及修改入口。
  指应用界面的纯色背景，不是导入背景图片；自定义颜色同步用于侧栏和控件的衍生配色。
- 设置抽屉与效果面板互斥。下拉展开/焦点变化不再触发整页布局；不移动位置未变的控件，
  效果面板刷新不再先隐藏所有子控件。自绘下拉与滑杆沿用原生键鼠行为，配色随主题变化。
- “无粒子”时禁用密度、速度、透明度，亮度/饱和度/冷暖仍可用；选粒子后恢复可调。
- 新增 `src/SettingsControls.inl`，集中原生控件绘制、设置选项同步与说明，未新增 UI 框架。
- 2026-10-05：设置页签、画质、全屏暂停、应用/取景屏幕、主题、缓存上限等控件新增悬浮说明。
  已选值的说明随设置变化；下拉列表中的各项也分别准备了简短解释。
  悬浮文字只在鼠标停留时显示，沿用 Windows 原生 tooltip，不增加常驻渲染。
- 本次验证：Release 编译和四组 CTest 通过；实际点击检查画质下拉及说明、深浅主题、
  自定义调色器打开/取消/确认、设置与效果面板互斥、无粒子时参数禁用、进度条残影修复。
  `publish` 已更新；原版与优化版 EXE 哈希未变。这轮未重跑 44 条视频及完整多屏/休眠回归。

- 萤火虫、细雨、飘雪：密度、速度、透明度可调；亮度、饱和度、冷暖可调。
  参数按素材独立保存。“对比原画”只影响预览；“恢复默认”重置当前素材。
  调参数不会立刻改变桌面，点击“应用到桌面”才提交桌面设置。
- 视频与 JPG/JPEG、PNG、BMP 图片统一加入素材库。可拖入文件、多个文件或文件夹；
  文件不复制、不转成新视频。拖入文件夹会把它设为当前壁纸文件夹。
- 收藏和最近使用；显式加入的单文件在刷新文件夹后仍保留；重新定位可继承收藏、效果、取景。
- 预览进度跳转。共享桌面预览中跳转会转成独立预览，不改变桌面视频的位置。
- 三个本地播放列表：常规、白天、夜晚；1/5/15/30/60 分钟间隔，顺序/随机，不连续重复。
  白天规则为本机时间 07:00–19:00，其他时间为夜晚。勾选才加入列表，默认不自动轮换。
  空列表保持现有壁纸，单项不重复建播放器；手动暂停、系统锁屏/睡眠、后台省电暂停时不轮换。
  自动轮换保持用户正在浏览的素材；手动“下一张”会把预览切到新素材。
- 可视化双屏示意：点击屏幕选择目标及取景屏幕，也可恢复全部屏幕。
  仍是同一素材单次解码，多屏独立取景；未加入多屏各自解码不同视频。
- 可选封面强调色（选择/封面就绪时采样一次，不逐帧分析）；可拖动预览/图库分隔线；窗口可缩放。
  预览表面固定保持 16:9 容器，源视频/图片再等比完整显示，不随拖动拉伸。
- 悬浮球小/标准/大三档、贴边收起、悬停口径说明和右键菜单；隐藏停止采样。

## 代码导读

- `WallpaperEffects.h`：统一参数范围与跨进程映射。一个控制器写，一个播放器读，零等待互斥；
  忙时沿用上一帧参数。进度、时长、跳转、帧计数使用原子整数。
- `EffectsRenderer.cpp`：原生 D3D11 着色器。颜色处理一次全屏采样，再实例化少量小四边形绘制粒子；
  不为每个像素遍历所有粒子，不回读视频帧到 CPU。关闭效果时释放专用纹理/着色器资源。
- `ImageSource.h`：Windows WIC 读取图片，限制超大图片长边 4096，CPU 像素只在上传期间存在。
  静态图片关闭粒子后不再持续绘制，通过低频命令检查响应调色，不持续执行 GPU 提交。
- `ControllerExperience.inl`：新增面板、素材偏好、播放列表、拖放、效果预览生命周期。
  依赖现有控制器命名空间，是编译期拆分，不是单独进程或动态库。
- `LibraryPreferences.h`：素材偏好保存格式、日夜列表选择、不重复轮换选择逻辑。
- `Player.cpp`：桌面与效果预览共用原生解码/绘制。`--preview-window` 模式只建立控制器子窗口，
  不接管 WorkerW、不恢复静态壁纸。桌面共享预览纹理仍保留原画，在 UI 内试调效果。
- `SharedPreviewRenderer.cpp`：对已应用素材复用后台原画纹理并绘制预览效果，不额外解码。

## 性能边界

关闭效果的普通视频仍用原有 MFPlay 预览；已应用同一视频时仍共享后台解码。
未应用的效果视频使用按需的原生预览进程，应用/换片/收回托盘后关闭它。
若预览另一条素材而桌面继续播放，会暂时有两个解码器；不是任何状态都只有一个进程。

粒子有额外 GPU 成本，非零效果会按输出尺寸申请 BGRA 工作纹理；多屏和高分辨率都会增加开销。
本轮没有承诺固定内存降幅或节能百分比，也没有生成特效视频缓存。原有画质代理功能仍可能生成缓存。
Windows 系统提供 Media Foundation、WIC、D3D11 和 D3DCompiler；不新增 CEF、mpv、FFmpeg 或联网服务。
不支持自动人物遮挡、深度识别、HDR 色彩管理；普通二维粒子不会自动绕到人物后面。

## 验证

- Release 编译及四组 CTest：效果参数/偏好/IPC/播放列表/GPU、原优化存储扫描内存、宿主几何、使用时长。
  效果测试真实编译 shader 并通过 WARP 读回像素，检查调色、三种粒子随时间变化、关闭后恢复原像素。
- `DWDEffectsIntegrationTests <exe> <video>`：真实硬件视频和测试 BMP，检查首帧、三种效果、
  时间跳转、暂停/恢复、关闭静态图片动画后停止帧计数、重新开启及正常停止。夹具在测试后移除。
- 原有 `DWDPreviewTests`：44 个 MP4 全部 ready/返回像素尺寸，包括竖屏、1906×1080 和 4K。
  快速切换、停止重开、无效路径后恢复、取消载入和限时关闭通过。不是完整观看每个文件。
- 使用电脑操作技能实际检查：收藏、右侧效果面板、飘雪预览/应用、播放列表勾选、两素材手动轮换、双屏面板。
- 双屏读回检查：2560×1440 与 1920×1080 的 WorkerW 输出几何正确；露出的副屏动态且非黑。
  当时主屏被其他应用遮挡，不算主屏实际像素动态验证通过。

未覆盖：真实跨天/跨时区轮换、完整自动轮换长时间运行、睡眠/热插拔/驱动失联、其他电脑、
严格 CPU/GPU/显存 A/B 基准。文件重新定位和拖放边界、不同 DPI 下悬浮球贴边体验仍应继续实机观察。
