# DWD

轻量原生 Windows 动态壁纸程序。免安装，所有 DWD 配置都保存在程序目录，无需 .NET、VLC、libmpv 或第三方解码 DLL。

## 当前版本

本目录是唯一维护的版本。运行 `publish/DWDNative.exe`；更新程序前请先从托盘退出正在运行的 DWD。

- “画面效果”：萤火虫、细雨、飘雪及亮度、饱和度、冷暖，支持原画对比和重置。点击“应用到桌面”才提交效果。
- “更多”：打开视频/图片、重新定位文件、播放列表、屏幕与外观。支持拖入图片或视频、收藏、最近使用和预览进度跳转。
- 播放列表支持定时、随机、白天/夜晚轮换，默认关闭自动轮换。
- 可拖动预览与图库之间的分隔线；悬浮球右键可调整大小、设置贴边收起。

效果默认关闭，启用粒子会增加 GPU 和工作纹理开销，不保证比普通视频更省内存。完整新增功能、实现导读和本轮验证范围见 [EFFECTS_NOTES.md](EFFECTS_NOTES.md)。

## 使用

1. 打开 `DWDNative.exe`，点击左下角齿轮，在“壁纸”中选择视频文件夹。
2. 点击右侧封面切换动态预览。顶部可以搜索和排序，底部可以翻页；目录有新视频时会自动刷新，也可手动“刷新视频”。
3. 点击预览右下角“应用到桌面”。默认应用到全部屏幕，也可在“播放”中选择单独一块屏幕。
4. 需要改变裁剪时，先在“壁纸”中选择取景屏幕，再点击底栏“调整取景”，拖动边框选择主体。各视频、各屏幕分别记住位置；再次应用后生效。
5. 底栏和托盘都可暂停/继续壁纸、恢复 Windows 静态壁纸。恢复静态壁纸不会关闭统计和控制界面。
6. 标题栏叉号及最小化按钮隐藏到托盘；唯一正常退出入口是托盘右键“退出程序”。

退出或选择“恢复静态壁纸”时，DWD 会等视频窗口移除后再请 Windows 恢复各屏幕的静态图片。如果原始图片已被移动或删除，会尝试使用 Windows 留存的转码副本，并在程序旁的 `Cache/StaticWallpaperRecovery.jpg`（或 `.png`、`.bmp`）留一份恢复文件；该文件不会被 DWD 的封面/视频缓存清理删除。若连系统副本也不存在，需要在 Windows 个性化设置中重新选择静态图片。

启动时托盘图标常驻。设置里的“启动时恢复上次壁纸”默认关闭；打开后，下次启动 DWD 会恢复上次应用的视频。这不是 Windows 开机自启动。

## 设置

- 壁纸：文件夹、上次壁纸恢复、分屏取景和恢复居中。
- 播放：原视频 / 均衡 / 节能画质；任一屏全屏时暂停 / 所有目标屏幕被全屏覆盖才暂停 / 关闭全屏暂停；应用屏幕。
- 外观：深色、浅色、跟随系统、自定义颜色；可隐藏内存悬浮球，隐藏后停止诊断采样。
- 缓存：目录、容量展示、优化视频预算（512 / 1024 / 2048 / 4096 MB）、清理封面和未使用的优化视频。
- 统计：活跃 / 观看两种前台口径、统计开关、当天及历史记录日排行；鼠标滚轮或滚动条浏览完整列表。

`DWDNative.ini` 放在 EXE 旁，采用 UTF-16 和临时文件原子替换，不往注册表保存配置。跟随系统主题只读取 Windows 的主题偏好。

## 性能与缓存

- 后台使用 Media Foundation + D3D11，单次解码后输出到多屏，各屏独立裁剪；预览已应用的视频时共享 GPU 画面，不重复解码。
- 预览另一个尚未应用的视频时，暂时会有两条解码。隐藏主窗口到托盘后释放预览解码。
- 原视频模式不生成压缩视频。均衡模式只优化明显高于目标屏幕分辨率的原片；节能模式按需生成最高 1080p、30fps 的 H.264 视频。
- 代理只处理比例接近目标屏幕的原片，避免竖屏、超宽源片被错误拉伸或优化后失真；不符合条件时继续用原视频。
- 首次转码会暂时增加资源占用；完成后复用磁盘上的压缩视频。内存里并不缓存完整原文件。
- 封面是 320×180 BMP，内存仅保留当前页、相邻页及当前预览封面；分辨率元数据每条仅 12 字节。
- 默认缓存为程序旁的 `Cache`。清理只针对 DWD 命名的缓存文件，不递归删除用户目录、不删除原视频；正在使用的优化视频受到保护。
- 缓存预算针对优化视频，按最近使用时间淘汰。保护中的当前视频可能使预算暂时超出；封面和很小的元数据不计入该预算。
- 目录通知是事件驱动的，变化后检查文件大小/修改时间稳定且无写入占用，再更新视频库。没有变化时不持续扫描文件夹。
- 锁屏、睡眠以及符合配置的全屏场景暂停播放；连续不可见 30 秒后释放解码器和输出资源，恢复时重新建立首帧。
- 播放器异常会尝试重新初始化，最多连续重试 3 次；失败后恢复静态壁纸并显示提示。

不同分辨率、编码、显卡驱动及多屏配置会影响内存，不能承诺所有视频都达到同一个占用数字。

## 使用时长与隐私

活跃模式在连续 60 秒无键鼠输入后暂停；观看模式只要求应用保持前台，锁屏和睡眠时暂停。两种计数同时保存，切换口径不混合历史。

记录位于程序旁 `UsageData/*.dwdusage`，按天保存应用名称、路径和累计时长，不保存窗口标题、输入内容、鼠标轨迹或截图。只统计 DWD 运行期间，不伪造安装前历史。休眠时间不计入统计；采样、消息延迟和异常长卡顿仍会有误差。

## 多屏与端口

支持扩展/复制模式和不同分辨率、比例、排列；复制模式按 Windows 提供的逻辑屏幕镜像输出。选择的屏幕暂时未连接时，回退到主屏。

正常显示配置变化时只调整 DWD 自己的窗口和渲染资源。已移除上一版的强制显示器刷新、唤醒重试和 W/D 计数。DWD 不给雷电/HDMI 接口断电，不禁用设备，也不改写 Windows 的显示拓扑。

系统要求：Windows 10/11 x64、正常 D3D11 驱动和 Windows 媒体组件。H.264 MP4 兼容性通常最好；其他格式取决于系统安装的 Media Foundation 解码器。

## 构建与测试

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
cmake --install build --config Release --prefix publish
```

发布目录仍然只有一个应用 EXE；后台播放和临时转码是同一个 EXE 的不同运行模式。测试程序只放在 build，不随应用发布。

日常修改只更新当前 publish，不自动制作压缩包或维护历史版本。
