# 独立优化副本（2026-10-03）

此目录完整复制自同级 `DWD.Native`，只在这里修改。原版源码与发布 EXE 未替换。
`src`、资源、构建配置、测试、开发备忘、学习文档、发布程序及便携数据均保留。
复制来的构建缓存包含原目录绝对路径，因此副本 `build` 已单独重新生成；可独立构建。
副本的缓存配置改为自己的 `publish/Cache`，不共用原版的缓存目录。

运行入口：`publish/DWDNative.exe`。原版和副本仍共用单实例互斥机制，避免两套程序争用桌面；
比较前先从托盘正常退出正在运行的那一版，再启动另一版。不生成压缩包。

## 本轮实现

1. `MemoryMetrics.h`：使用 `PROCESS_MEMORY_COUNTERS_EX2.PrivateWorkingSetSize` 汇总私有物理工作集，
   旧系统使用 `QueryWorkingSet` 只计非共享页。查询失败显示“暂不可用”，不换成提交量冒充。
   覆盖控制器、当前播放器、临时转码器以及正在退出的旧进程。与任务管理器采样时刻、
   四舍五入可能不同；不是完整的 GPU 显存统计，也不保证和“活动私有工作集”每一刻完全一致。
2. `AsyncFileStore.h`：UI 提交 UTF-16 值快照；单写线程按目标路径合并，默认去抖 600ms。
   配置内容未改变不提交；不同日期的统计各自保存。保留临时文件、刷新和原子替换。
   正常退出排空待写数据；配置错误在状态栏反馈，统计写失败允许后续重新保存。
3. `ProcessCleanup.h`：旧播放器/转码器退出在后台等待，UI 不再等待正常交互中的 3/5 秒超时。
   命名事件仍优先优雅退出。句柄在等待线程结束后才关闭，退出应用时排空清理任务。
   转码临时文件含控制器 PID 与代次，避免取消旧任务时删除新任务的文件。
4. `LibraryScanner.h`：后台扫描/排序/写入占用检查；请求与结果各一个槽位，过期代次丢弃。
   UI 按路径、文件大小、修改时间合并，保留未变化的封面和尺寸。不在刷新时 join 封面线程。
   复制未结束的文件延后自动刷新；权限错误不会被误认成一直正在复制。
5. 预览媒体线程先完成元数据读取与代理缓存选择，再建立媒体项。设置快照按值传递，
   后台不访问 UI 全局变量。首次打开也能命中已有优化视频，12 秒超时覆盖准备阶段。
6. 绘制入口对后备画布设置脏区；图片、文字、圆角绘制先检查可见区域。卡片圆角裁剪与
   原脏区求交并用 SaveDC/RestoreDC 恢复，不再把局部裁剪覆盖掉。
   `ScaledBitmapCache.h` 缩放图片最多 8 MiB，源句柄删除前失效，避免句柄复用误命中。
7. 封面优先顺序为选中项、当前页、相邻页；原始 320×180 封面最多 32 张（约 7 MiB）。
   翻回最近页可复用；暂停封面工作用条件变量，不再 10ms 轮询。搜索复用小写名称并去抖。
8. 共享纹理身份未变时直接复用；更换纹理时保留有效 D3D 设备；暂离预览/托盘保留最多 10 秒，
   到期释放。仍保留 MFPlay 与共享预览两个独立 HWND，不混用渲染链。
9. 播放等待改为可中断的条件变量；明显迟到帧跳过 GPU 显示处理，不跳压缩数据的解码。
   首帧绝不跳过；连续最多跳五帧后显示并调整时间基准，避免低性能机器一直没有新画面。
10. 优化视频的新转码任务在停止浏览至少 5 秒且没有另一条前台预览解码时启动；应用新的
    壁纸先取消旧转码任务，优先保证首帧。修复封面尺寸转换失败返回已删除句柄的边界问题。

## 不应夸大的部分

- 本轮是响应路径、调度和资源复用优化，不是更换视频解码架构，没有承诺内存或 CPU 固定降幅。
- 图片缓存和 10 秒共享资源保留以有上限的内存换取响应速度；内存数字变小也包含统计口径修正。
- D3D 设备创建/释放仍可能经过 UI 线程；底层驱动长期不返回仍有风险。
- 真正退出时仍等待配置保存、目录/封面线程清理；正常刷新/点击/收回托盘不再承担这些等待。
- 高频 VideoProcessorInputView 缓存、MFPlay 音轨裁剪、转码原帧率策略没有贸然修改：
  它们涉及解码表面生命周期、格式兼容和缓存版本，需要另做针对性验证；不是本轮收益的依据。
- 44 个视频测试确认加载事件与像素尺寸，不是逐个视频长时间观看、显存测量或严格帧率基准。

## 测试入口

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

`DWDOptimizationTests` 验证 1000 次配置提交、最终快照、UTF-16、跨日目标、原子替换、错误报告、
私有工作集、后台扫描/过期结果、迟到帧边界与缩放图复用。夹具仅在当前构建目录创建后删除。
真实视频测试沿用 `DWDPreviewTests`，双屏只读采样沿用 `DWDWallpaperTests`。

详细验证与未覆盖范围见 `REGRESSION.md` 的副本新增记录。
